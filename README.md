# Botanical CDN

Historical botanical illustrations for the Rootwork project — public domain art from 1675-1900.

**Live:** (Asset repository, served via GitHub raw URLs)
**Stack:** Static image assets
**Status:** Maintained

## What This Is

Botanical CDN is an image repository containing high-quality scans of historical botanical illustrations. These images are used by the Rootwork medicinal plant database as plant profile artwork. Sources include Köhler's Medicinal Plants (1887), Flora Batava, Sturm's Flora, Curtis's Botanical Magazine (1787), and Maria Sibylla Merian's works (1675).

All images are public domain. The collection covers 100 medicinal plants matching Rootwork's database.
